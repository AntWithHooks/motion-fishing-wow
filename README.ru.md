# 🎣 Motion Fishing

**Рыбачь в World of Warcraft: Forever с помощью движений iPhone.**

[🇬🇧 English](README.md) · [Сообщить об ошибке](../../issues/new/choose) · [Участие в проекте](CONTRIBUTING.md)

> **Статус:** экспериментальный проект. Исходники и Windows-сборка будут загружены отдельно. **Готового EXE в Releases пока нет.**

## Что это

Motion Fishing — бесплатное Windows-приложение, превращающее iPhone в контроллер рыбалки для **WoW Forever**. Делаешь движение удочкой назад-вперёд — заброс; дёргаешь руку к себе — подсечка.

Бесплатное приложение [phyphox](https://phyphox.org/) передаёт ускорение и ориентацию телефона на компьютер **по локальной сети Wi-Fi**. Bluetooth и отдельное iOS-приложение не нужны.

```text
iPhone + phyphox      Wi-Fi         Motion Fishing на Windows           WoW Forever
Акселерометр и ориентация ───────► CAST / HOOK / UNKNOWN ── клавиша ──► Аддон рыбалки
```

## Возможности

- **CAST:** заброс из двух фаз — назад → вперёд.
- **HOOK:** обучаемая подсечка к себе с проверкой направления и вращения.
- **NEGATIVE:** примеры нежелательных движений — например, пронация и супинация.
- **UNKNOWN:** никаких игровых действий, если движение не прошло проверки.
- **Локальная система координат:** ориентация фиксируется в начале каждого движения.
- **Обучение:** сохранение примеров и настройка чувствительности.
- **Профили:** общий `profiles/default.json` и личный `profiles/settings.json`.
- **RU / EN:** явный переключатель языка на верхней панели.

Программа не распознаёт поклёвку автоматически и не рыбачит без движений игрока.

## Что понадобится

Windows 10/11, iPhone с бесплатным [phyphox](https://phyphox.org/), одна доступная локальная сеть для телефона и компьютера, WoW Forever и аддон рыбалки на одной клавише.

**Python другим игрокам не понадобится**, когда будет опубликована собранная Windows-версия.

## Быстрый запуск

1. Установи **phyphox** на iPhone.
2. Импортируй эксперимент **Acceleration and Attitude**.
3. Подключи телефон и ПК к одной локальной сети. Компьютер может использовать Ethernet.
4. В phyphox открой эксперимент, нажми **Play**, включи **Remote Access** и скопируй показанный адрес.
5. Когда появится готовый релиз, скачай ZIP из **Releases**, распакуй и запусти `MotionFishing.exe`. Стандартный GitHub *Source code ZIP* — это не готовая программа.
6. В Motion Fishing укажи адрес phyphox и нажми **Подключить**.
7. Проверь клавишу рыбалки в WoW (например, `F8`) вручную и выбери эту же клавишу в приложении.
8. Запиши примеры **CAST, HOOK, NEGATIVE**. При проверке отключи отправку клавиш; после проверки включи и переключись в WoW.

После загрузки полного проекта здесь появятся PDF-инструкции на русском и английском.

**Никогда не загружай личный `profiles/settings.json` в публичный репозиторий.**
